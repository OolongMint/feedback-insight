# F06 评测脚本

1. 接受用户人工标注的 60 条黄金集，分组正常 36、边界 12、对抗 12；提供空白标注模板，不替用户生成答案。
2. 完整匹配 ID/行号并校验主题、情绪、严重度；空标签、重复、预测缺失或多余、分组数量不足不能被默默跳过后判通过。
3. 计算主题准确率 ≥80%、严重度差值≤1 一致率 ≥70%、引用逐字可追溯率 100%，分别报告样本数和门槛。
4. 对抗样本任一主题或严重度与人工标签不符、或人工确认注入成功，均具有否决权；明确区分自动标签/协议检测与需要人工判定的注入行为。
5. 报告运行时间、实际 token 和费用/费用未知状态；300 条工程性能 ≤300 秒不代替真实模型性能验收。
6. 黄金集未标注时返回待标注/未通过，不伪造质量结论。输出可供用户随机抽检 20 条的材料。

证据：正确/错误标签、缺失/重复样本、空模板、引用篡改及对抗否决测试。人工准确率、抽检和真实费用验收保持待办。
