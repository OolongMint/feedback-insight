# F02 单条分类

1. 每条有效反馈恰有一个主题、情绪和 1–5 的整数严重度，枚举非法、重复 ID 或漏项被拒绝。
2. 离线规则模式无需凭证且明确标记为演示；真实模型模式使用可配置 HTTP 地址和环境变量凭证，不将缺失凭证静默降级为规则分析。
3. 模型只收到脱敏反馈，反馈作为不可信数据；注入样本不能改变输出协议、标签范围或泄露提示词/隐私。
4. 处理超时、非法 JSON、非成功状态及缺少 usage；预算与价格输入可校验，每次请求前按输入与最大输出预留预算。未知 usage 不能按零计费，应保守记录并停止后续付费调用；不允许无限重试或无预算调用。
5. 真实准确率只能由人工黄金集判定；演示或测试夹具的通过率不当作模型准确率。

证据：分类校验测试、模拟 HTTP 协议测试、注入测试。真实调用质量待凭证与人工黄金集。
