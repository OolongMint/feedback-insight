# F04 洞察摘要与原话引用

1. 每条引文按记录 ID/源物理行号取自脱敏明细，文本必须逐字相同；校验失败不得发布报告。没有 PII 的引文也可直接在原始 CSV 找到。
2. 证据充足的主题取 2–5 条代表性反馈，已知用户 ID 不重复；未知身份不能冒充不同真实用户。样本不足时显示“数据不足”。
3. 单条主题、空主题、同用户重复反馈等诱导编造场景均不能补造证据。
4. 摘要不得引入无证据的具体数字或功能名；统计数字由程序计算。机会点是待验证方向，不做跨主题因果断言或承诺解决方案。
5. 300 条数据下摘要步骤 ≤60 秒，真实模型调用记录实际 usage 和费用，规则模式为零调用并明确标记。

证据：引用篡改拦截、用户去重、稀疏主题及摘要约束测试。
