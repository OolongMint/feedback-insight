# F01 数据导入与脱敏

1. 导入含 UTF-8 BOM、中文或约定英文字段的 CSV；正确处理引号、逗号和多行字段，记录反馈的 CSV 物理起始行号。
2. 缺少文本/日期列、非法日期、空文本、重复或格式异常数据有明确处理记录，不能静默丢失且不说明。
3. 在模型调用之前脱敏手机、邮箱、订单号和用户配置的敏感词，覆盖文本、渠道及其他可自由输入字段；日期严格校验，用户编号转为不可逆代号。姓名等无法保证自动识别，说明人工审核边界。
4. 原始 PII 不出现在持久化输出、模型请求、错误日志或 HTML；源文件留在本地且不被改写。
5. 提供 240–300 条明确标记的合成反馈；不生成“人工黄金标签”。

证据：导入/脱敏单元测试及多行 CSV 场景。状态由独立 Evaluator 判断。
